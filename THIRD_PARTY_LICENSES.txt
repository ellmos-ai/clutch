1. RUNTIME ARCHITECTURE & DEPENDENCY FOOTPRINT
--------------------------------------------------------------------------------

clutch is engineered as a provider-neutral, local-first, zero-egress LLM
orchestration engine and model router. It analyzes task complexity and purpose,
dispatches to optimal model gears (G1-G5), tracks financial budgets with a 4-zone
fuel gauge, enforces persistent circuit breakers, and learns through experience.

Mandatory Runtime Dependencies:
Package                 Version Spec    License       Type      Purpose
--------------------------------------------------------------------------------
anthropic               >=0.40.0        MIT           External  Anthropic Claude client
google-genai            >=1.0.0         Apache-2.0    External  Google Gemini client
requests                >=2.31.0        Apache-2.0    External  HTTP client for Ollama/Kimi
Python Standard Library >=3.10          PSF-2.0       Built-in  argparse, asyncio, sqlite3

Optional Web Interface Dependencies ([web]):
Package                 Version Spec    License       Scope     Purpose
--------------------------------------------------------------------------------

uvicorn                 >=0.27          BSD-3-Clause  [web]     ASGI web server
python-multipart        >=0.0.9         Apache-2.0    [web]     Multipart form parsing

Development, Quality & Test Tooling:
Package / Tool          Version Spec    License       Scope     Purpose
--------------------------------------------------------------------------------
pytest                  >=7.0           MIT           [test]    Unit & contract tests
ruff                    >=0.6           MIT/Apache-2  [linter]  Code formatting & lint
setuptools              >=68.0          MIT           [build]   Packaging standard
wheel                   >=0.40          MIT           [build]   Wheel distribution

Network calls are strictly restricted to user-configured LLM provider endpoints
(Anthropic, Google, Ollama, Kimi, or local/remote OpenAI-compatible APIs).
Zero telemetry, tracking, or background telemetry egress exists.
